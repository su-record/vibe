## Result (2026-09-09/10 KST, 450-line cohort, sha256 5fd3914573bc628d590f8a5aa9f1e728f766e58f313bfbda391ab681e563f583) — gate passes
Three arms, five runs per arm and client, both clients. Quality equal everywhere: every arm scored full marks on every task. `on` vs `off` and `scoped` vs `off`, weighted tokens (turns):
- settlement 0.72 (4.6) / 3.08 (21.4) on claude; 0.80 (10.4) / 3.48 (34.2) on codex — `off` 7.8 and 9.2 turns
- vibe-fix 1.19 (4.0) / 3.52 (16.0); codex 1.01 (7.2) / 2.94 (17.6)
- report 1.21 (4.2) / 5.79 (20.6); codex 0.85 (7.8) / 4.72 (22.2)
- session-split 0.69 (6.8) / 2.35 (30.8); codex 0.81 (13.6) / 1.47 (31.2)
- brownfield 0.61 (8.6) / 1.30 (48.4); codex 0.50 (14.6) / 3.84 (70.8)
- handover, claude→codex 0.75 (8.2) / 2.28 (31.8) — one task, two clients, no memory between: the state carries it for a quarter less than the bare model spends
- anomaly (retired) 1.75 / 2.33 on claude (scoped n=3, two runs lost to API 500); 1.60 / 1.90 on codex

**What scoping costs, measured for the first time.** The `scoped` arm — the card, the skills and the hooks with no intent, vibe running discover and scope itself — spends 1.3× to 5.8× the bare model's tokens and reaches the same quality. Saying what counts as success and binding each scenario to a check is not free, and this is what it costs.

**anomaly is retired.** Bare models scored 3/3 five times of five on both clients: they read `docs/finance.md` on their own. Six trap tasks in a row have now failed to separate the arms (hidden file, shared helper, forty modules, a reset in the path, missing terms, undocumented finance rules). The task, its fake user and its judge stay on disk; `--task anomaly` still runs it.

**What the run cost in evidence.** 50 re-measured runs: 47 usable, all full marks, zero stalled, three lost to API 500 on Claude (anomaly scoped ×2, ask off ×1). Error rows are kept, never replaced by a rerun, and the gate counts usable rows only — a fix Codex made during this release after finding that missing evidence could pass the old gate.
