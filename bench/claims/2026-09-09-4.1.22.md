# Pre-registered claim — 4.1.22, run on 2026-09-09

Written before the bench runs; not adjusted after seeing the data.

- Task: `brownfield` — this repository at the 4.1.21 release commit, one cross-cutting change (a `lines` rule for the `file` check through validation, the check, the README table and the scope skill), judged by build + tests + two file checks + `vibe size`. Five scenarios, so the `on` arm runs `size: full` with the map and `vibe context` on.
- Arms: claude × {on, off}, codex × {on, off}; five runs per arm; `--parallel 3`; both arms isolated; the judge counts the task's scenarios only.
- Quality: `on` checks not worse than `off`.
- Tokens: `on` weighted input tokens (`input + 0.1 × cacheRead + 1.25 × cacheWrite`) ≤ `off` × 0.7 per client, over runs both arms passed (`--metric tokens --paired`).
- Also reported, no rule: turns, wall-clock, reported cost.
- Whatever falls is reported as measured.

## Result (2026-09-09, 20 runs, both arms isolated, map and context on for `on`)
- Quality: claude 5/5 in every run on both arms; codex `on` 5/5 every run, `off` 5,4,5,5,5. `--metric checks` inconclusive (ranges overlap). Not worse.
- Tokens (weighted input, runs with token counts): claude `on` 115,277 (n=3) vs `off` 110,953 (n=2) — `insufficient-runs` for a verdict, and the means say the map did not save; codex `on` 744,958 vs `off` 593,411 (n=4 each, `insufficient-runs` by the pairing rule) — `on` spent about 25% **more**. The gate's context rule fails: `on` is over `off` × 0.7 for claude and codex alike. **The pre-registered claim is falsified.**
- Turns: claude 20.0 vs 18.5; codex 29.4 vs 21.2. Wall-clock: claude `on` 156 s vs 199 s (inconclusive, `on` faster); codex 287 s vs 238 s. Cost, claude: $0.87 vs $0.90.
- Reading: on a 54-file repository with a client that caches its prompt, the bare model's rediscovery is already cheap — claude's `off` runs carry ~30 fresh input tokens and ~590k cache reads (59k weighted); there is little for a map to remove. What `vibe context` and per-scenario checks add (five contexts of up to 12,000 characters, five `vibe check <id>` calls) outweighs it. Graft's 42–60% is measured on larger repositories and on cold reads; neither condition holds here. The one signal in the harness's favour is claude's wall-clock (156 s vs 199 s), which the range test cannot confirm.
- Bench defects seen: two claude `off` runs and two `on` runs lost their JSON (turns and tokens null), which starved the paired token comparison; `bench/run.js` must capture the client's usage even when the final JSON is missing (stream-json, or a retry of the parse on the last line).
- No saving is claimed for 4.1.22. What is claimed: on this repository, with the map and context on, the harness costs 4–25% more tokens at equal quality.
