# Local pilot and review policy

This is synthetic task data. Use local exports only. Customer mail is represented by files, not a connected account. Keep source records unchanged. Prepare drafts for a person to review before any external send. Automated payment is not permitted. No permission changes, real messages or package installation are authorized.

For status drafts retain each event's date, team, status, blocker and source reference. For follow-up drafts retain action text, owner and due date when recorded, and explicitly mark missing owner/due information. Do not fill missing information from names or meeting dates.
